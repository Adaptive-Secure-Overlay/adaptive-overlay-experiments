# Итог быстрого закрытия экспериментальных замечаний

Выполнены только локальные вычисления и повторная обработка сохранённых EVE-NG артефактов. Новый сетевой прогон, физический Keenetic, внешняя инфраструктура, закрытые большие серии и DOCX не затрагивались.

## Статус 4 пунктов

1. Порог 0,5 / n50: `completed_computational_calibration`, критерий `True`; 800,000 детерминированных модельных маршрутов. В исходной диссертации определено `α=0,5`; допустимого `α=50` нет.
2. Длина каскада: `completed_offline_eve_reanalysis`, критерий `True`; H=3/4/5, по 400 сохранённых опытов на H; потери ping по H: 0, 1, 5 из 800 пакетов на группу.
3. Реестр доверия: `blocked_product_gap`; три локальные guard-проверки прошли, но удалённая подмена ключа принимается непроверенным каталогом. Защищённый реестр не подтверждён.
4. Множественные старты: `completed_offline_eve_reanalysis`, критерий `True`; 27/27 успешных строк, 0 % потерь и 0 прямых финальных IKE A/B.

## Граница выводов

Калибровка порога является вычислительным экспериментом внутри модели F4, а пункты 2 и 4 — новой проверяемой агрегацией ранее полученных EVE-NG данных, не новым живым прогоном. Пункт 3 не закрыт: требуется продуктовая реализация аутентифицированного реестра и её исполняемые негативные тесты.

## Проверка

Запустить `python validate_results.py --root .` из этой папки. Итог сохраняется в `validation.json`.

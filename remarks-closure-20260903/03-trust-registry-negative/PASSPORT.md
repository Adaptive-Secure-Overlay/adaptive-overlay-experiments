# Паспорт 3. Негативные тесты реестра доверия

- Гипотеза: защищённый реестр должен отклонять отсутствующий, неизвестный и подменённый узел до построения маршрута.
- Параметры: четыре локальных случая; временные X25519-ключи существуют только в памяти; сеть и EVE-NG не используются.
- Стенд и версии: CPython `3.12.13`, сохранённый `universal_cascade.py`, SHA-256 `F77D9E524E9B781267988C7E06D12C97AF85C28DE6645336340618D35D809B45`.
- Число прогонов: 4.
- Критерий успеха: три входных guard-проверки отклоняют плохие данные, а защищённый реестр отклоняет удалённую подмену ключа.
- Сырой артефакт: `raw-negative-cases.csv`.
- Агрегат: `result.json`.

| Случай | Ожидалось | Наблюдалось | Проверка |
|---|---|---|---:|
| local_public_key_substitution | reject | reject | True |
| missing_member_key | reject | reject | True |
| unknown_destination | reject | reject | True |
| remote_public_key_substitution_without_signed_registry | reject_if_registry_authenticated | accept | True |

Результат: `blocked_product_gap`. Локальные проверки целостности собственного ключа, полноты каталога и неизвестного назначения сработали. Подмена удалённого публичного ключа была принята переданным каталогом: подписанный/аутентифицированный реестр и доверенный источник обновлений не реализованы в проверенном пути. Это фиксация блокера, а не успешная атака на защищённый реестр.

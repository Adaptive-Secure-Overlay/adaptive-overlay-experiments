# Минимальный быстрый план

Оценка до выполнения: 20–40 минут при пригодности сохранённых артефактов.

1. Детерминированная калибровка модельного порога α=0,5 вокруг n50.
2. Повторная агрегация 1200 сохранённых EVE-NG опытов по H=3/4/5.
3. Четыре локальных негативных теста каталога ключей; при отсутствии аутентифицированного реестра — блокер разработки.
4. Нормализация 27 сохранённых одновременных стартов в матрицу потерь, RTT, времени установки и пакетов.

Сетевой запуск EVE-NG не входит в быстрый план: нет свежего preflight и подтверждённого rollback.
